# Onboarding editor components

Agreement publication applies to first-time onboarding. Existing consent remains
valid, and the localized editor hint states that policy explicitly.

- `OnboardingWelcomeEditor.vue` edits bilingual welcome-message cards and their order.
- `OnboardingAgreementEditor.vue` edits bilingual agreement cards, titles, icons, colors, and order.
- `onboardingEditor.ts` normalizes the pair data and serializes it into the existing onboarding API contract.
